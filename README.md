# Responsive Product Card — UI + AI

## Descripción
Proyecto enfocado en la generación de una interfaz responsiva utilizando IA y el análisis del código HTML y CSS resultante.

## Problema
Es importante que diseñadores UX/UI comprendan cómo se estructura una interfaz en código para colaborar mejor con desarrollo.

## Solución
Se generó una tarjeta de producto responsiva mediante IA a partir de prompts definidos.  
Posteriormente se analizó el HTML y CSS para identificar:
- estructura visual  
- breakpoints  
- comportamiento responsive  
- mejoras posibles  

Se iteró el diseño mediante nuevos prompts y se documentaron hallazgos.

## Resultado
El proyecto permitió comprender la relación entre diseño visual y código, reforzando habilidades de handoff y diseño técnico.
